# 📥 Przewodnik Pobierania - Walentynka

## Szybki Start

### Opcja A: Nie mam zainstalowanego Pythona/Git (NAJPROSTSZA) 

#### Pobierz tylko stronę HTML:

1. **Kliknij ten link prawym przyciskiem myszy:**
   ```
   https://raw.githubusercontent.com/rtjhvg/Walentynka/copilot/add-simple-html-page/index.html
   ```

2. **Wybierz "Zapisz jako..." lub "Save link as..."**

3. **Zapisz plik na swoim komputerze**

4. **Otwórz plik w przeglądarce** (podwójne kliknięcie)

✅ **GOTOWE!** Strona walentynkowa działa!

---

### Opcja B: Chcę mieć wszystkie pliki (ZIP)

#### Krok po kroku z obrazkami:

1. **Otwórz stronę repozytorium:**
   ```
   https://github.com/rtjhvg/Walentynka
   ```

2. **Znajdź zielony przycisk "Code"** (lub "<> Code") w prawym górnym rogu

3. **Kliknij na niego** - rozwinie się menu

4. **Wybierz "Download ZIP"** - ostatnia opcja w menu

5. **Poczekaj aż plik się pobierze** (nazwa: Walentynka-copilot-add-simple-html-page.zip)

6. **Rozpakuj ZIP** na swoim komputerze:
   - Windows: Prawy klik → "Wyodrębnij wszystko" lub "Extract all"
   - Mac: Podwójne kliknięcie na plik ZIP
   - Linux: `unzip Walentynka-copilot-add-simple-html-page.zip`

7. **Otwórz folder** - wszystkie pliki są tam!

✅ **GOTOWE!** Masz wszystkie pliki lokalnie!

## Co znajduje się w plikach?

## FAQ - Często zadawane pytania

### ❓ Czy muszę mieć Pythona?

**NIE!** Możesz po prostu pobrać plik `index.html` i otworzyć go w przeglądarce.

Python jest potrzebny tylko jeśli chcesz:
- Automatycznie wygenerować email
- Utworzyć wersję do wysłania emailem

### ❓ Który plik powinienem pobrać?

**Zależy co chcesz zrobić:**

1. **Tylko zobaczyć stronę** → Pobierz `index.html`
2. **Wysłać emailem** → Pobierz wszystko (ZIP) i użyj skryptów Python
3. **Pokazać komuś lokalnie** → Pobierz `index.html` i otwórz w przeglądarce

### ❓ Jak otworzyć plik HTML?

1. **Windows:** Podwójne kliknięcie → otworzy się w domyślnej przeglądarce
2. **Mac:** Podwójne kliknięcie → otworzy się w Safari/Chrome
3. **Linux:** Podwójne kliknięcie lub `xdg-open index.html`

Możesz też:
- Przeciągnąć plik do okna przeglądarki
- W przeglądarce: Plik → Otwórz plik (Ctrl+O)

### ❓ Strona nie działa po pobraniu!

**Sprawdź:**
1. Czy plik ma rozszerzenie `.html` (nie `.txt`)
2. Czy otworzyłeś w przeglądarce (nie w notatniku)
3. Czy pobrałeś cały plik (nie tylko część)

**Rozwiązanie:**
- Użyj "Zapisz jako..." zamiast kopiowania tekstu
- Upewnij się że plik nazywa się `index.html`

### ❓ Nie mogę pobrać plików - jestem na telefonie

**Na telefonie Android:**
1. Otwórz link w Chrome/Firefox
2. Przytrzymaj link → "Pobierz link" lub "Download link"
3. Znajdź w folderze Pobrane

**Na iPhone/iPad:**
1. Otwórz link w Safari
2. Przytrzymaj → "Pobierz plik połączony"
3. Znajdź w aplikacji Pliki

### ❓ Czy mogę edytować pliki?

**TAK!** Możesz edytować:
- `index.html` - zmień tekst, kolory, pytanie
- Skrypty Python - dostosuj treść emaila

Użyj edytora tekstu (Notepad++, VS Code, Sublime)
